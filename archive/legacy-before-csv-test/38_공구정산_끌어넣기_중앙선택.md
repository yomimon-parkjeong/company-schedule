# 공구정산: 엑셀 끌어넣기·중앙 선택창

2026-10-14

공구정산 중앙의 큰 영역에 엑셀을 끌어 놓으면 화면 중앙에 수수료율 선택 팝업이 열린다. 파일 선택 버튼으로 넣어도 같은 절차를 따른다.

선택한 파일명과 정산 대상(사업자·일반 개인), 수수료율 10%·15%·20%를 팝업에서 확인한다. 상단 정산 대상은 “정산 전 대상 유형 사전 확인필요”라는 설명 영역이며 클릭·선택·클릭 모션을 제공하지 않는다. 대상 유형은 엑셀을 넣은 뒤 중앙 팝업에서 선택한다. 수수료율은 파일마다 직접 선택하며 기본값을 적용하지 않는다.

정산 대상과 수수료율을 고른 뒤 정산 불러오기 버튼을 눌러야 파일을 읽고 계산한다. 취소·ESC는 대기 파일을 해제하고 기존 정산·대상·수수료를 유지한다. 손상 파일도 기존 결과를 보존한다. 불러오기 중 추가 파일로 중복 계산하지 않는다.

.xlsx 파일 1개, 최대 20 MB를 받는다. 드래그 중 테두리와 배경이 변하고 잘못된 형식·여러 파일·빈 파일에는 안내를 표시한다. 기존 정산 결과가 있어도 같은 영역에서 새 파일을 넣을 수 있다. 수수료율 변경 팝업도 화면 중앙에 열린다.

기존 취소·입금대기·반품완료 제외, 교환완료 포함, 쿠폰 별도 차감 안 함, 사업자 세금 미공제와 개인 세목별 버림 계산을 유지한다. 일정표 매출에 자동 반영하지 않는다.

공개 페이지에는 가상 일정만 포함한다. 선택한 엑셀은 해당 브라우저 안에서 처리하며 서버에 업로드·저장하지 않는다.
