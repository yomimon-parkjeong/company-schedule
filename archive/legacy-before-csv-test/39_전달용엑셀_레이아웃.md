# 전달용 정산 엑셀 레이아웃 (2026-10-14)

사용자 요청에 따라 웹 정산 미리보기는 유지하고 다운로드하는 전달용 엑셀 서식만 개선했습니다.

- 쿠폰 열의 원본값은 참고용으로 보존합니다. 쿠폰 합계 수식을 제거하고 합산 제외로 표시하며 수수료·세금·지급액에서 합산하거나 차감하지 않습니다.
- 전달용 요약의 정산 제외 내역은 취소건으로 표시합니다. 취소·입금대기·반품완료(복합 완료 상태 포함) 행은 A:J 전체에 연한 노란 배경과 빨간 글자를 적용합니다. 교환완료는 기존처럼 포함합니다.
- 머리글, 주문 합계, 소득세, 공구수수료 정산, 최종 지급액을 색상과 구분선으로 구별합니다. 사업자의 세금 영역은 회색으로 표시합니다.
- 주문 기본 높이는 64pt에서 28pt로 줄였습니다. 긴 원본 상품명·처리현황·공구명·파일명은 줄 수에 따라 행 높이를 조정합니다.
- 원본 주문 행·순서·금액·상태를 보존하며 정산·일정 매출 연결의 계산 기준은 변경하지 않았습니다.

## 구현

서식은 .work/settlement-calculator/build-template.mjs에서 @oai/artifact-tool로 작성하고 export-template.xlsx를 만듭니다. prepare-template.py는 이 서식의 셀 스타일과 병합 정보를 template.json으로 추출합니다. settlement.js의 settlementWorkbook 함수가 브라우저에서 실제 주문 수에 맞는 수식·조건부서식 범위를 조립합니다.

전체 HTML 재생성은 .work/import2026/integrate_import.py입니다. 정산 웹 UI·불러오기·금액 계산·일정표 연결 함수는 이번 수정에서 변경하지 않았습니다.

## 검증

가상 주문으로 브라우저에서 생성한 개인·사업자 × 10·15·20% 전달용 6개를 검증했습니다.

- 상태 제외, 웹 표시 유지, 파일 생성 18개 검사 통과.
- XLSX 내부 XML·수식·취소 강조 A:J 범위·행 높이·쿠폰 원본값 보존을 6개 파일과 25행 파일에서 확인.
- 6개 파일을 스프레드시트 엔진으로 다시 계산해 지급액 일치 확인.
- 수수료와 원본 판매가 변경 시 지급액 재계산, 쿠폰 변경 시 지급액 불변 확인.
- 개인·사업자 주문부·정산부 렌더링을 시각 검토. 일반 주문 28pt, 긴 상품명 검증 행 88pt.
- Microsoft Excel 앱에서의 직접 확인은 수행하지 않았습니다.

실제 과거 일정 1,679건은 유지하고 공개 베타에는 가상 일정 228건만 사용합니다. 검증 결과는 개발자 전달 자료의 quality/settlement-export-layout-verification.json에 포함합니다.
