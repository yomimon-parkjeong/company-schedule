# 쿠폰 항목 제거 (2026-10-15)

최신 사용자 요청에 따라 정산 화면, 전달용 엑셀과 별도 디자인 초안에서 쿠폰 금액 열·합계·설명 문구를 모두 제거했습니다. 39번 문서의 쿠폰 참고값 보존 기준은 이 범위에서 변경합니다.

## 입력과 출력

- 정산 표준 컬럼은 번호, 주문일자, 상품명, 수량, 판매가, 구매자, 주문번호, 처리현황, 택배사/송장번호의 9개입니다.
- 원본 DB 엑셀에 쿠폰 열이 있어도 읽을 수 있습니다. 필수 컬럼을 열 이름으로 찾고 쿠폰 열은 읽거나 숫자 검사·합산하지 않습니다. 쿠폰 열이 없는 9컬럼 자료도 같은 방식으로 불러옵니다.
- 내부 주문 values는 9항목입니다. 구매자[5], 주문번호[6], 처리현황[7], 택배 정보[8]이며 book·주문 행에 coupon 필드를 두지 않습니다.
- 전달용 엑셀은 A:I 9열입니다. 제외 조건과 색상 규칙은 H열의 원본 처리현황을 사용합니다. 기존 취소·입금대기·반품완료 제외, 교환완료 포함은 유지합니다.
- 주문 식별 해시는 쿠폰 없는 동일한 9항목으로 만듭니다. 쿠폰 열 유무·값만 다른 자료는 같은 입력으로 인식합니다. 현재 링크·매출은 페이지 메모리에만 있으며, 기존 영구 저장 구현은 없습니다. 추후 서버 이관 시 과거 해시와 신규 해시의 기준 차이를 검토해야 합니다.
- 정산 기준 매출·수수료·세금·지급액과 일정표의 판매건수·주문금액 연결은 유지합니다.

## 검증

- 브라우저 검증 48개 통과: 9열 파일, 기존 10열 파일, 열 순서 변경, 쿠폰 값 무시, 동일 식별값, 구매자·주문번호·처리현황·택배 정보 위치, UI 제거, 개인·사업자 10/15/20% 출력, 새 출력 재불러오기.
- 브라우저가 만든 6개 XLSX를 스프레드시트 엔진으로 재계산해 지급액 일치를 확인했습니다. 판매가·수수료 변경 후 재계산도 확인했습니다.
- 6개 실제 출력과 2시트 디자인 초안의 XML·오류 셀·쿠폰 표기 미포함을 확인했습니다. 쿠폰 열을 숨기는 방식이 아니라 실제로 제외합니다.
- 개인·사업자 출력의 주문/정산부와 디자인 초안을 렌더링해 확인했습니다. Microsoft Excel 앱 직접 검증은 하지 않았습니다.
- 실제 일정 1,679건과 공개 가상 일정 228건을 유지합니다. 2시트 디자인은 계속 별도 초안이며 베타의 시트 구성을 바꾸지 않았습니다.
