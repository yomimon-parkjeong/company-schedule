# 공구정산 대상과 수수료율 반영

반영일: 2026-10-13

## 확정한 기준

- 정산 대상은 사업자와 일반 개인입니다.
- 사업자는 소득세·지방소득세 공제만 제외합니다. 다른 금액 계산은 동일하며 부가세를 추가하지 않습니다.
- 일반 개인은 첨부 전달용 파일의 기존 3.3% 공제 방식을 유지합니다. 소득세 3%를 10원 단위로 버림하고, 해당 소득세의 10%를 지방소득세로 계산해 다시 10원 단위로 버립니다.
- 쿠폰은 판매가 합계에서 별도로 차감하지 않습니다.
- 엑셀 넣기 전에 10%, 15%, 20% 중 수수료율을 선택합니다. 자동으로 선택되는 기본값은 없습니다.

## 처리현황 반영 기준

| 처리현황 | 정산 매출 포함 |
| --- | --- |
| 취소·취소완료 | 제외 |
| 입금대기 | 제외 |
| 반품완료 | 제외 |
| 반품완료 - 환불완료 | 제외 |
| 교환완료 | 포함 |
| 교환완료 - 발송완료 | 포함 |

복합 표기는 완료 상태별로 판별하고 원본 문구를 보존합니다. 제외 내역은 유효 주문 건수·판매 수량·정산 기준 매출에 포함하지 않습니다. 원본 주문 전체 합계는 그대로 보이며 제외 내역을 별도로 차감합니다. 부분 취소·환불 또는 미확정 처리현황은 차감 수량·금액 확인이 필요하며 이전 정산을 유지합니다.

브라우저의 73개 검증 항목과 화면 크기·유형별 검증을 통과했습니다. 취소·입금대기·반품완료·복합 표기·교환완료가 섞인 테스트 자료로 건수·수량·매출·지급액을 확인했고, 개인·사업자 전달용 엑셀을 별도 계산 엔진으로 재계산해 화면과 같은 합계를 확인했습니다. 원본 엑셀과 기존 일정 데이터는 수정하지 않았습니다.

## 사용 흐름

공구정산 → 정산 대상 선택 → 엑셀 넣기 → 수수료율 선택 → .xlsx 파일 선택 → 정산 미리보기 → 전달용 엑셀 다운로드

수수료율 선택창은 화면 오른쪽 아래의 작은 알림창 형태이며 선택을 기다립니다. 취소하거나 닫으면 파일 선택이 열리지 않습니다. 기존 파일의 수수료율을 변경할 때도 같은 창을 이용하며 취소하면 이전 계산을 유지합니다.

정산 대상을 바꾸면 지급액과 전달용 시트 유형을 함께 변경합니다.

## 전달용 시트

- 사업자: 전달용_사업자. 소득세 계산과 세금 공제 영역을 회색으로 표시하고 공제액은 0으로 계산합니다.
- 개인: 전달용_개인. 소득세·지방소득세·총 공제액·지급액을 표시합니다.
- 선택한 대상의 시트만 다운로드합니다.
- 주문 내역 10개 열과 하단 정산 구성을 바탕으로 실제 주문 행 수에 맞춰 합계·수식 범위를 생성합니다.
- 입력한 수수료율을 연결해 계산합니다. 수식에 15%를 고정하지 않습니다.
- 금액은 숫자로 저장하며 천 단위 쉼표를 표시합니다. 소수 금액이 생기면 소수 둘째 자리까지 표시해 숨기지 않습니다.
- 원본 주문의 판매가는 수량이 반영된 행 금액으로 사용하며 수량을 다시 곱하지 않습니다.
- 주문번호 기준 건수와 판매 수량은 따로 표시합니다.

## 검증

실제 첨부한 주문 파일로 사업자·개인 × 수수료율 10%·15%·20%의 여섯 조합을 확인했습니다.

| 대상 | 수수료율 | 수수료 | 소득세 | 지방소득세 | 지급액 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 개인 | 10% | 19,170원 | 570원 | 50원 | 18,550원 |
| 개인 | 15% | 28,755원 | 860원 | 80원 | 27,815원 |
| 개인 | 20% | 38,340원 | 1,150원 | 110원 | 37,080원 |
| 사업자 | 10% | 19,170원 | 0원 | 0원 | 19,170원 |
| 사업자 | 15% | 28,755원 | 0원 | 0원 | 28,755원 |
| 사업자 | 20% | 38,340원 | 0원 | 0원 | 38,340원 |

브라우저에서 실제 파일 읽기, 미리보기, 유형 변경, 수수료율 변경·취소, 파일별 출력, 출력 재입력, 누락 값 처리, 취소 차감, 1행·300행 확장을 검증했습니다. 출력한 여섯 파일은 별도의 스프레드시트 계산 엔진에서 다시 계산했고 수수료율 변경 시 지급액이 함께 변경되는 것을 확인했습니다. 실제 Microsoft Excel 앱의 실행 검증은 아닙니다.

화면과 전달용 시트의 개인·사업자 표시를 검수했고 좁은 화면에서도 계산 표가 화면 밖으로 넘치지 않도록 수정했습니다.

## 보존과 지원 범위

일정표의 기존 JavaScript와 222개 일정 데이터는 그대로 보존했습니다. 정산의 주문 내역과 계산값은 별도로 관리하며 일정표 매출에 반영하지 않습니다. 원본 두 엑셀은 변경하지 않았습니다.

프로젝트 파일·검증 파일·출력은 모두 D:\타임블럭 아래에 저장했습니다. 기능은 외부 라이브러리나 업로드 서비스 없이 HTML 안에서 동작합니다.

현재는 제공된 DB 주문 형식의 .xlsx 파일을 지원합니다. 알 수 없는 처리현황이나 부분 취소·환불은 차감 수량·금액을 추정하지 않고 확인 요청을 표시합니다.
