# 개발자 인계 — CSV 반영 전 시안
기준일: 2026-10-19

## 시작
developer-empty/만 전달하거나 저장소에서 해당 폴더를 사용합니다.
실행은 public/index.php, 초기 일정은 0건입니다. 단계별 설명은 developer-empty/README.md를 따릅니다.
스크린샷 전사 데이터를 내장하거나 함께 불러오지 않습니다. CSV를 직접 넣어 신규·갱신·동일 건수와 달력 반응을 시험합니다.

## 유지한 기능
전체일정/주차/공구정산, 일정 등록·편집 팝업과 알림, 담당자·유형·색상 관리, 월·주·SKU 집계, CSV 입력, 정산 엑셀 입력·계산·출력, 확인 후 일정 매출 연결을 유지합니다.
일정표 판매건수는 유효 주문번호 중복 제거 건수이며 판매 수량과 구별합니다.
정산의 일정 매출액 연결은 사용자 확인 후 주문금액을 사용합니다. 기존 값이 있으면 합산 확인과 중복 자료 방지를 유지합니다.

## 현재 저장 방식
- 일정·매출·정산·CSV 반영: JavaScript 메모리. 새로고침하면 일정 0건.
- 월 선택·담당자/유형 등 설정: 해당 브라우저 localStorage. 공용 저장 아님.
- CSV: public 밖에 있는 수동 입력 자료. PHP가 자동으로 읽지 않음.
- 과거 스크린샷·전사·교정 기록: archive 보존. 현재 실행 대상 아님.

## 후속 구현이 필요한 부분
PHP/DB 저장 API와 스키마, 공용 저장·충돌 처리, 로그인·권한, 감사 이력·백업, 서버에서의 입력 검증과 파일 업로드 제한을 설계해야 합니다.
sourceId 중복 방지와 CSV 재입력 시 직원 편집값·매출 보호 규칙은 서버 이관 시에도 유지해야 합니다.
정산 자료에는 개인정보가 있으므로 서버 접근 권한과 파일 보관·삭제 정책을 적용해야 합니다.
원본 CSV는 전체 상품명 교정 완료본이 아닙니다. 이미지 전사의 교정 기록을 전체 CSV에 무조건 적용하지 않습니다.

PHP/DB가 구현됐다고 설명하거나 이 시안을 운영 저장 시스템으로 취급하지 마세요.
