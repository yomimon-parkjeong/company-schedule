# 1단계 검토: 날짜 클릭 → 일정 등록
기준일: 2026-10-20

## 이번 단계
- 월간/주차 달력의 날짜 숫자 또는 날짜 칸 빈 공간을 누르면 기존 일정 등록 팝업을 엽니다.
- 시작일과 종료일은 클릭한 날짜로 채웁니다. 앞뒤 달 날짜도 해당 날짜를 사용합니다.
- 날짜 버튼은 Enter/Space로도 열립니다.
- 기존 일정 바는 기존 편집 팝업으로 연결합니다.
- 기존 상단 일정 등록·등록 완료 알림은 유지합니다.
- 2단계 담당자 표기/바 높이, 3단계 취소 정산 처리는 아직 수정하지 않았습니다.
- 실제 일정·CSV·매출 데이터 및 회사 서버·DB는 변경하지 않았습니다.

## 사용자 검토
GitHub Pages에서 날짜 숫자/빈 공간을 눌러 날짜를 확인하고, 테스트 일정 등록 후 일정 바를 눌러 편집 동작을 확인해주세요.
미리보기의 입력은 새로고침하면 초기화됩니다.
1단계 검토 완료 후 2단계를 진행합니다.

## PHP 전달
현재 GitHub의 developer-empty/public/index.php는 서버 DB 연동 전 클라이언트 시안을 기반으로 한 검토용 파일입니다.
회사 서버의 로그인·DB 연결·저장 코드는 여기에 포함되어 있지 않습니다.
**회사 서버의 index.php를 이 파일로 통째로 덮어쓰지 마세요.**
개발자는 php-date-click.patch의 날짜 버튼·등록 함수·CSS 변경만 기존 서버 파일에 병합하고, 기존 저장 이벤트와 DB 연동을 유지해야 합니다.
기존 상단 등록 버튼도 openAddForDate()를 호출하도록 통일합니다. 등록 submit/DB 저장 경로 자체는 변경하지 않습니다.
적용 후 날짜 클릭, 선택일 입력, 기존 일정 편집, 실제 DB 저장/재조회, 로그인 유지 여부를 회사 서버에서 확인합니다.
