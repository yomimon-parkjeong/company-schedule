# v59 누락 수수료 표시 보완 — GitHub 미리보기

월 매출 종합의 기존 세 지표 아래에 정산 기준 매출·세전 수수료 합계·수수료 차감 후 금액을 추가합니다. SKU 및 인플루언서별 매출액 오른쪽에는 최종 지급수수료를 표시하고 제품/전체 합계에도 같은 계산을 적용합니다. 주차 보기와 주차별 SKU 상세에서도 선택된 공구만 사용합니다.

집계 대상은 기존 화면의 공구 선택 기준과 같습니다. 선택 월 진행/공구 시작일, 취소 제외, 주차 구분을 그대로 따릅니다. 해당 공구의 전체 정산 이력을 합산하며 주문일·지급일 기준 월 분할을 새로 적용하지 않습니다. 한 공구가 두 달에 걸치면 진행 월 기준에서는 두 달에서 해당 공구의 전체 실적이 보일 수 있으므로 안내를 표시합니다.

기존 주문금액(gross)은 변경하지 않습니다. 새 차감 지표는 같은 정산 건에서 매출과 세전 수수료가 모두 확인된 범위만 계산합니다. 원가·배송비 등을 반영한 순이익이 아닙니다. 최종 지급수수료는 저장된 세금 공제 후 지급 예정액이며 실제 송금 완료액과 구분합니다.

이력이 없거나 금액이 없으면 미등록, 일부만 있으면 확인 건수와 미연결 공구 수를 표시합니다. 확인된 0원은 0원으로 표시합니다. 동일 자료 해시는 합계에서 한 번만 계산하며, 서로 다른 자료의 일부 주문 중복을 해결하는 기능은 아닙니다. 모든 합계는 소수점 두 자리의 정수 단위로 더해 소수 오차를 방지합니다.

조회와 합산만 수행하며 일정·정산 이력·매출을 저장하거나 재합산하지 않습니다. 기존 엑셀 출력 형식은 유지합니다. 테스트 자료는 로컬에서만 사용하고 공개 초기 일정은 0건입니다. 실제 DB·백업 JSON을 GitHub에 올리지 않습니다.

summary.js/css와 apply-preview.py가 변경 소스입니다. apply-preview.py로 검토 PHP에 적용한 뒤 tools/build-pages-preview.py로 Pages 파일을 생성합니다. 운영 v59 PHP는 이번 작업에서 변경하지 않았으며 이 미리보기 PHP를 사내 운영 파일로 교체하지 않습니다. 사내 최종본은 사용자 확인 후 현재 운영 Firebase 통합본에 병합합니다.
