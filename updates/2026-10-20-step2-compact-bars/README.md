1단계 날짜 클릭 등록은 사용자 검토 완료. 2단계 사용자 검토 대기.

## 이번 변경
- 캘린더 바에서 '담당자의 일정' 둘째 줄을 제거하고 일정 제목만 표시합니다.
- 월간 바 56→34px, 주차 바 64→40px. 제목 글씨 15px는 유지합니다.
- 겹친 일정 행에 맞춰 주차 영역 높이도 줄어들도록 계산합니다.
- 담당자 데이터, 고유 색상, 마우스 안내/접근성 이름, 편집창, 담당자 필터·집계는 유지합니다.
- 긴 제목은 한 줄 말줄임으로 표시하고 마우스 안내와 편집창에서 전체 내용을 확인합니다.
- 1단계 날짜 클릭 등록은 유지하며, 3단계 취소·환불 정산은 아직 수정하지 않았습니다.
- 실제 일정·DB·매출 및 회사 서버는 변경하지 않았습니다.

## 미리보기
초기 일정은 0건입니다. 테스트 일정을 등록하거나 본인의 CSV를 수동 반영해 바 표시를 확인하세요.

GitHub Pages 입력은 새로고침하면 초기화됩니다.

## 회사 PHP 서버에 병합
검토용 public/index.php에는 회사 서버의 로그인·DB 연결·저장 코드가 없습니다.
**회사 서버 파일을 이 PHP 전체로 덮어쓰지 마세요.**
- 1단계가 회사 서버에 이미 적용된 경우: stage2-only.patch 변경분만 병합.
- 1단계도 아직 적용되지 않은 경우: stage1-and2.patch로 두 단계 변경분을 함께 확인해 병합.
- 두 패치를 동시에 적용하지 않습니다. patch 경로는 GitHub 전달본 기준이므로 실제 회사 서버 경로에 맞춰 개발자가 변경 내용을 병합합니다.
- 날짜 클릭 등록, 기존 일정 편집, 담당자 필터/집계와 회사 DB 저장·재조회를 회사 서버에서 확인합니다.
