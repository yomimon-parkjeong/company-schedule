# 특이사항 표시 선택 · 개발자 병합 안내

1~3단계 사용자 확인 완료 후 추가한 변경입니다. 회사 서버/DB에는 직접 적용하지 않았습니다.

## 동작
- 등록·편집의 특이사항 아래 `일정 바에 특이사항 표시` 체크를 추가했습니다. 기본값은 해제입니다.
- 기존 일정과 CSV 신규 반영도 설정값이 없으면 숨깁니다. boolean true만 표시하며 문자열 `"false"`/`"true"`는 표시 허용으로 처리하지 않습니다.
- 월간·주간 바, 마우스 안내, 접근성 이름, 목록 요약과 등록/수정 토스트에 같은 표시 기준을 적용합니다. 체크 여부와 무관하게 편집 창의 특이사항 원문은 유지합니다.
- 이전 코드가 title 끝에 합친 특이사항은 렌더링할 때 분리합니다. 줄바꿈/공백을 정규화해 기존 접미부를 제거하며 원본 CSV·originalTitle·specialNotes를 지우지 않습니다. title 자체에만 있고 specialNotes에 분리되지 않은 개인정보는 추측해 삭제하지 않으므로 개발자가 원본을 확인해야 합니다.
- 기존 색상·담당자·제품·매출·취소 정산 기준은 유지합니다. CSV 재반영은 직접 선택한 표시 설정을 보존합니다.

## 회사 DB 코드에 병합할 때
현재 public/index.php는 DB 연결 코드가 없는 검토용 원본입니다. 회사의 index.php와 통째로 교체하지 마세요.

- 1~3단계가 이미 반영되어 있으면 notes-only.patch를 병합합니다.
- 1~3단계도 아직 없으면 stages1-to3-and-notes.patch를 참고해 누적 변경을 병합합니다. 두 패치를 함께 적용하지 않습니다.
- 일정 모델/DB에 showNotesOnCalendar 불리언을 추가합니다. DB 타입은 TINYINT(1) NOT NULL DEFAULT 0에 해당하는 필드를 사용하고 기존 행도 0으로 시작합니다. 실제 테이블명·열 이름은 담당 개발자가 정합니다.
- 등록/수정 API는 체크 여부를 명시적으로 저장하고 조회 API도 반환해야 합니다. DB의 0/1을 프런트엔드에서는 false/true로 명시적으로 변환하세요. Boolean("0") 같은 변환은 금지합니다.
- CSV를 새로 넣을 때 false로 시작하고 기존 일정의 사용자 선택은 CSV 재입력으로 덮어쓰지 않습니다. 새 필드를 scheduleCsvCalendarFields에 추가하지 않습니다.
- 이 설정은 화면 요약 표시 설정입니다. 편집·원본 CSV 미리보기·기존 원본 내보내기에 대한 접근권한 기능은 아닙니다. 기존 title의 자동 합치기 로직이나 서버가 별도로 생성하는 툴팁이 있다면 같은 표시 함수를 적용하세요.

## 검증
가상 CSV의 공동구매/행사, 기존 제목에 붙은 메모, 여러 줄 메모, 체크/해제 후 재편집, 신규 등록 기본값과 미리보기, 월간34px/주간40px, 등록 알림, CSV 재입력 설정 보존을 확인했습니다. 브라우저 오류 0건이며 기존 정산 상태 회귀 검사 33건도 통과했습니다. 실제 개인정보는 공개 미리보기나 검증 자료에 넣지 않았습니다.

GitHub Pages와 이 PHP의 편집값은 현재 화면 메모리에만 유지됩니다. 회사 DB 저장은 위 병합 작업으로 연결해야 합니다. PHP 엔진·회사 DB에서의 실행은 이번 검증 범위에 포함하지 않습니다.
