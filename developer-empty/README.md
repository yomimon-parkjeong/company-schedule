# CSV 반영 전 개발자 전달본
기준일: 2026-10-19

## 실행
PHP 실행 환경에서 이 폴더를 기준으로:
    php -S 127.0.0.1:8080 -t public
브라우저에서 http://127.0.0.1:8080/ 를 엽니다.
index.php는 기존 HTML/CSS/JavaScript 화면을 PHP 경로로 실행하는 시안입니다. PHP/DB 저장 API를 새로 구현한 버전은 아닙니다.

## 시작 상태와 CSV 반영
- public/index.php의 초기 일정 배열은 비어 있습니다. 내장 실제/가상 일정, CSV 자동 로딩, JSON 자동 로딩은 없습니다.
- 담당자·업무유형·기준 상품명·공휴일 정보와 달력·정산 기능은 유지합니다.
- 상단 일정 원본 CSV → 파일 선택 또는 끌어놓기 → 미리보기/신규 건수 확인 → 일정표에 반영으로 시험합니다.
- data/의 CSV는 public 밖에 있는 수동 입력용 원본입니다. 코드가 자동으로 읽지 않습니다.
- 이 CSV는 1,679건의 기존 원본이며 상품명 전체 교정 완료본이 아닙니다. 상품명 교정 CSV의 제작은 별도 검토·확정 범위입니다.
- 같은 CSV를 다시 넣으면 동일 내역은 중복 추가되지 않아야 합니다.
- CSV 반영·일정 편집·매출·정산 연결은 현재 페이지 메모리에만 유지되며 새로고침하면 일정 0건으로 돌아갑니다.
- 화면 설정의 localStorage 키도 개발자 테스트 전용으로 분리했습니다.
- 현재 대시보드와 공개 베타는 이 전달본으로 교체하지 않았습니다.

## 확인 순서
1. 첫 진입: 달력에 일정 0건, 공구 건수 0건, 매출 미입력, CSV 반영 전 안내.
2. 원본 CSV 미리보기: 1,679건 신규. 적용 전에는 달력이 비어 있음.
3. 반영: 2023~2027년 해당 월 이동, 목록·주차·담당자·매출 대상 반응 확인.
4. 같은 CSV 재선택: 동일 1,679건, 일정 수 증가 없음.
5. 새로고침: 일정 0건으로 초기화.
6. DB 연결 시에는 초기 이관과 운영 저장을 분리하고 이 메모리 초기화 정책을 교체.

현재 실제 기록 범위는 2023-02-10~2027-01-01입니다.
검증: 동일 HTML/JavaScript 화면으로 초기 0건, CSV 신규 1,679건 반영, 동일 1,679건 재인식, 새로고침 0건 복귀를 확인했습니다. 로컬 PHP 실행기가 없어 PHP 서버 실행·php -l 검사는 수행하지 않았습니다.
