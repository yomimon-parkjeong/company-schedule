# CSV 등록으로 시작하는 개발자 전달본
기준일: 2026-10-19

## 실행
이 폴더에서 PHP 서버를 실행합니다.

    php -S 127.0.0.1:8080 -t public

브라우저에서 http://127.0.0.1:8080/ 를 엽니다.
실행 진입점은 public/index.php 하나입니다. 기존 HTML/CSS/JavaScript 화면을 PHP 경로로 제공하는 시안이며, PHP/DB 저장 API는 아직 없습니다.

## 초기 상태
- 내장 일정 0건. 이미지 전사 일정·가상 일정·매출 입력값이 없습니다.
- 이미지 비교 화면, 전사 데이터 JSON, 캘린더 스크린샷은 이 전달 폴더에 포함하지 않습니다.
- CSV/JSON 자동 로딩을 하지 않습니다. data/의 CSV도 수동 테스트 입력 파일입니다.
- 담당자·업무유형·색상·상품 제안·공휴일과 일정·정산 기능은 유지합니다.
- 설정 키는 company-schedule.dev-empty. 접두사로 기존 대시보드와 분리합니다.

## CSV 반영 시험
1. 첫 진입 시 달력 일정 0건과 CSV 반영 전 안내를 확인합니다.
2. 상단 '일정 원본 CSV'에서 data/의 CSV를 선택하거나 끌어 넣습니다.
3. 미리보기에서 신규 1,679건을 확인한 후 '일정표에 반영'을 누릅니다.
4. 2023~2027년 해당 월의 달력·목록·담당자·주차 집계 반응을 확인합니다.
5. 같은 파일을 다시 선택하면 동일 1,679건이며 중복 추가하지 않습니다.
6. 현재 시안은 메모리에만 반영하므로 새로고침하면 일정 0건으로 돌아갑니다.

원본 CSV의 실제 기록 범위는 2023-02-10~2027-01-01입니다.
원본 CSV는 상품명 전체 교정 완료본이 아닙니다. 이미지 전사 222건의 과거 교정 기록을 CSV 1,679건 전체에 일괄 적용하지 않았습니다.
화면에서 변경한 일정·매출·정산 연결도 새로고침하면 초기화됩니다. 운영 시 PHP/DB 저장과 공유·권한 구현이 필요합니다.

## 검토 결과와 보존 범위
CSV 등록으로 스크린샷을 코드에 내장하던 입력 방식을 대체할 수 있습니다.
자세한 검토 범위는 CSV대체_검토.md를 확인하세요.
현재 실제 대시보드와 공개 베타는 변경하지 않았습니다.
GitHub의 과거 비교 자료와 생성 과정은 archive/legacy-before-csv-test/에 별도 보존하며, 이 전달 폴더에는 포함하지 않습니다.

기존 브라우저 검증에서 초기 0건 → CSV 신규 1,679건 반영 → 동일 1,679건 재인식 → 새로고침 0건 복귀를 확인했습니다.
이번 정리는 실행 코드의 변경 없이 전달 구성과 문서만 정리했습니다.
로컬 PHP 실행기가 없어 PHP 서버 실행·php -l 검사는 수행하지 않았습니다.
