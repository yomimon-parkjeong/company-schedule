# 이미지 전사 자료의 CSV 대체 검토
기준일: 2026-10-19

## 판정
일정 입력 경로는 CSV 등록으로 대체 가능합니다. 이미지 파일이나 이미지 전사 JSON을 읽어야 동작하는 기능은 개발자 전달 PHP에 없습니다.

| 확인 항목 | 전달본 동작 |
|---|---|
| 최초 일정 | 빈 배열, 0건 |
| 입력 경로 | 일정 원본 CSV → 선택/끌어놓기 → 미리보기 → 사용자 반영 |
| 제목·기간·상품·닉네임·색상 등 | CSV 파서와 일정 변환 경로로 반영 |
| 담당자 | 명시된 담당자 우선, 기존에 확인된 색상/카테고리 매핑 활용, 불명확한 경우 미확인 유지 |
| 공구·페이백 구분 | 기존 제목 형식 분류 규칙 유지 |
| 재입력 | sourceId 기준 신규·갱신·동일 판별. 직원 편집값·매출 보호 |
| 이전 이미지 전사 222건 | 초기 일정 및 자동 입력 대상에서 제외 |
| CSV 1,679건 | 별도 수동 입력용 원본으로만 제공 |
| 영구 저장 | 미구현. 새로고침하면 일정 0건 |

## 대체의 의미와 한계
대체 가능하다는 것은 일정 등록·표시 기능이 CSV 입력으로 동작한다는 뜻입니다.
이미지에서 전사한 222건과 원본 CSV 1,679건이 같은 데이터라는 뜻은 아닙니다.
이미지 전사 당시 정리했던 상품명 교정은 원본 CSV 전체의 교정 완료를 보장하지 않습니다.
담당자·상품이 불분명한 원문은 임의로 확정하지 않습니다.
스크린샷 자체의 시각적 대조나 과거 교정 근거는 CSV의 기능 대체 대상이 아니므로 과거 자료로 따로 보존합니다.

## 보존과 정리
- 개발자 전달 폴더에는 캘린더 스크린샷·이미지 전사 JSON·내장 일정 데이터를 넣지 않습니다.
- GitHub의 기존 채워진 HTML·정규화 JSON·스크린샷·이전 생성 과정·과거 설명서는 archive/legacy-before-csv-test/에 보존합니다.
- archive는 과거 참고 자료이며 실행 경로나 자동 데이터 공급원이 아닙니다.
- 실제 사용 중인 D드라이브 대시보드, 원본 CSV, 원본 이미지와 공개 베타는 변경하지 않았습니다.

## 검증 근거
앞선 동일 화면의 브라우저 검증: 초기 0건, CSV 신규 1,679건, 반영 후 동일 1,679건, 새로고침 0건, 콘솔 오류 0건.
이번 정리: PHP 실행 파일 바이트 동일, 일정 빈 배열 유지, 이미지/JSON 자동 입력 참조 없음, CSV 원본 해시 동일, 실제 대시보드 해시 동일, ZIP 무결성 확인.
PHP 엔진 실행 검사는 아직 수행하지 않았습니다.
